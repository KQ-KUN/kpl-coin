# 0.3.2：两次点击与可读性修订

默认100枚投入时，历史操盘现在为「点选战队 → 确认并揭晓」。第二次点击直接显示本场真实比分、命中情况、净收益与更新后的余额。「继续历史」直接进入下一场赛前卡片，不再出现预留本金页、日期批确认页或赛季确认页。跳过一次点击即可揭晓，之后继续下一场。自选投入金额仍为50/100/200/500，修改金额需要额外选择动作。

## 独立交互版本与冻结边界

新增 `src/interactive.mjs`，版本 `series-reveal-v1`。继承已验收 `Session`，沿用它的输入检查、原 `release`、统计与 `finish`；原 `release` 调用唯一 B 账本的 `settle`。没有另写任何金额、赔率或统计公式。

操盘现在在确认本场后立即结算，所以资金可用时点及回撤曲线与冻结的日期批交互不同；余额紧张时可参与的后续比赛也可能不同。这属于明确的玩法交互版本，不能宣称逐场余额仍等于旧日期批模式，不能当作真实历史资讯与资金可用时序的还原。操作顺序按已有比赛日期和稳定存储顺序推进。原始比赛日期和结果可用日期均未修改，逐场曲线仅采用比赛展示日期。

死忠模式仍使用原 `engine.mjs` 日期批结算。原引擎、唯一账本、模型、模拟赔率、比赛数据、质量状态与队徽快照的冻结哈希均通过；原 A/B/B.1 和 E 0.3.0 验收包未改。赛前胜率和近五场仍来自原数据与严格过去的结果截止规则；赛前卡片不显示该场答案。

## 可读性与视觉

- 比赛主要辅助文字至少14px，队名18px，模拟倍率24px；桌面队名20px、倍率28px。
- 双方队徽放大，赛前卡片把胜率、倍率、近况分开呈现，减少重复说明。
- 揭晓卡保留双方队徽与队名，突出32px大比分和28px净收益。
- 命中红色、未命中绿色，同时使用命中/未命中文字与方向符号。
- 已选择的战队与投入在揭晓后仍可见但禁用；继续按钮替换确认行，维持面板和曲线坐标。
- 手机卡片保持固定尺寸；放大字体时解除固定高度，优先保证完整可读。
- 同日逐场曲线在日期跨度为0时按事件顺序绘制，避免第一场收益只显示为一个小竖线；金额与日期不变。
