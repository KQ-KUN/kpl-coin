## 两种模式的体验

死忠选择本命后默认3×自动播放，可随时暂停、改速、跳至结算、重启或更换。本轮把开始按钮放在选择区上方，播放控制放在赛前卡片前，避免覆盖队伍卡片和把暂停藏在长曲线之后。普通比赛展示真实阶段、BO、日期和双方历史名；总决赛只强调边框与文字，倍率和收益不变。赛季结果短暂出现后继续。

历史操盘每张赛前卡可选择A、B或跳过，金额50/100/200/500。确认先预留，同日选择结束后或更晚批次集中揭晓。这个日批流程保留B已批准资金语义，不能为了立即播一场比分就提前释放返还。“结束回放”让剩余未决策比赛不参与，绝不虚构玩家参与。

结算支持截图、查看逐季结果和复制摘要；剪贴板不可用时的文本回退也已验证。复制的自动测试使用clipboard替身，不读取或写入个人剪贴板；浏览器不支持时提供文本框手动复制。当前没有保存进度或跨设备状态同步。

## 当前风险与下一步

本轮是桌面Edge的移动视口模拟，未测试真实手机、移动Safari、低性能设备和触摸滚动。系统字体在不同设备有差异；没有下载新字体。26张既有队徽保留原像素，火豹原图缺失，当前只显示明确的文字标识。没有把UUG队徽混给火豹。

运行时JSON符合预算，但没有测移动网络下载、手机解压或内存峰值。高倍播放会快速跳过文字，玩家需暂停或选1×阅读；跳至结算可直接获得准确总账。1,989场自主模式很长，提供剩余不参与的结束入口，未加入任务、排行或自定义仓位。

实际时刻、三场隔离缺口、V1概率校准与边际偏差、公开再分发许可仍沿用既有审计边界。C以历史娱乐定位呈现，不将模拟收益解释为现实博彩收益。

审核后的视觉工作建议集中在赛果出现时的简短反馈、赛季转场节奏、日期/资产变化的可读性和结算截图的更紧凑版式。保留暂停、跳过和reduced-motion；不增加随机奖励、幸运倍率、充值、提现或付费复活。火豹旧队徽只能在获得已有可靠授权素材后补充，不能用当前provider图强行继承。

正式Hub接入、线上部署、存档设计和真实设备验收分别另行授权。本次完成后停止，等待反向审计。
