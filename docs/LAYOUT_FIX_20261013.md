# 0.3.1 本地布局修订

用户要求消除播放中的上下跳动，减少上端留白，并让主要内容和操作尽量保持一屏。仅修改页面结构、样式、展示文案和相关浏览器测试；原 E 0.3.0 验收包保留，未更新生产站或启用正式入口。

## 修复依据

修复前的独立 Edge 录制中，赛前、记录选择、揭晓和赛季结束之间，比赛卡片高度及曲线位置变化 150.953125px。极速播放还使用不同的曲线顺序。360×740 下首页原文档高 2,559px，播放曲线的底部在视口外。

当前采用固定的比赛面板和曲线区域；普通与极速共用布局，浏览器不再锚定动态内容。手机卡片高度 228px；操盘卡片 196px；桌面卡片 320px。较长日期批的内容允许在卡片内滚动，卡片支持键盘焦点；每个新事件从内部顶部展示，不滚动整个页面。所有比赛仍完整结算。大幅文字放大时取消固定高度，允许纵向阅读。

## 页面调整

- 刊头压缩为单行，删除重复标题、介绍、模式编号和辅助说明。
- 桌面保留完整副标题一行；手机使用「10,000 枚硬币，重走 KPL 历史。」。
- 战队列表局部滚动，27 个实体全部保留，已选队伍、实际场次与开始按钮始终在列表外。
- 常规/极速播放共用固定位置；暂停、速度、极速、跳至结算和重新开始均保留，触摸按钮至少 44px。
- 操盘结束与重开移至标题行，赛前胜率、赔率、近五场和投入控件保留。
- 结算采用紧凑网格，全部原有统计和新增指标保留；正常参与计数的重复说明收起，余额不足警示仍显示。逐赛季结果仍可展开。
- 红涨绿跌不变，纯虚拟计分、非官方声明与模拟赔率说明保留。

## 验证

`npm test` 33/33；`npm run build` 成功。冻结核心、唯一账本、数据与队徽哈希检查通过，运行时 JSON 仍为 274,553 字节。`npm run test:layout` 使用独立桌面 Edge 上下文，对 360×740、390×844、430×932、768×1024、1440×900 检查首页、回放和操盘页面一屏、无横向溢出；结算主要操作同屏。回放采样覆盖 preview / recorded / result / season，页面滚动、面板高度、面板位置及曲线位置的变化范围均为 0px。极速切换后位置相同，106 个极速帧检查通过，AG 最终仍为 12,077.03。

200% CSS 布局缩放与 reduced-motion 已检查。放大后允许纵向滚动，没有强制缩小字号或裁切卡片。浏览器证据位于 `verification-layout/before` 和 `verification-layout/after`；完整交互回归位于 `verification-layout/regression-current`。移动视口与 Android UA/触摸均为桌面浏览器模拟，不是 Android/iOS 真机验收。

最终 `npm run test:browser` 30/30 通过：暂停/重启/隐藏页面、快速切速、操盘胜负/跳过/不足余额、复制替身及降级、曲线节点复用、触摸目标、赛前答案隔离均通过。真实浏览器计时器的极速耗时为 AG 13.14 秒、狼队 13.70 秒、eStar 12.12 秒；对应余额 12,077.03 / 12,859.74 / 8,942.92。AG 普通 10× 完整回放为 52.06 秒，结算结果相同。

本地服务 `http://127.0.0.1:5180/` 已确认返回 `data-version="0.3.1"`，刷新页面即可加载。展开规则、逐赛季长列表、极小高度或放大字体仍可能需要滚动；余额不足警示及极长内容以完整可读为先。
